📋 PROBLÈME INITIAL :
─────────────────────────────────────────────────────────────────────────

Le fichier NEW_AMC_TOUT_EN_UN_OPTIMISE.command générait BEAUCOUP de faux
positifs avec les paramètres suivants :

  • AMC_SEUIL = 0.03 (3%)         ❌ TROP BAS !
  • AMC_BW_THRESHOLD = 0.15       ❌ TROP BAS !

Résultats observés :
  • Notes très basses pour tous les élèves
  • Paul MEGEVAND (21) : 12/44 (5.45/20)
  • Rayan SOUMARE (28) : 7/44 (3.18/20)
  • Estelle CELINAIN (5) : 0/44 (0/20) - Aucune détection !

Cause : Le seuil à 3% est trop proche des cases vides (~1%), donc il
détecte les salissures, ombres, artefacts de scan, etc.

═══════════════════════════════════════════════════════════════════════════

✅ SOLUTION MISE EN PLACE :
─────────────────────────────────────────────────────────────────────────

Nouveaux paramètres OPTIMISÉS (basés sur la documentation AMC) :

  • AMC_SEUIL = 0.08 (8%)         ✅ OPTIMAL !
  • AMC_BW_THRESHOLD = 0.25       ✅ OPTIMAL !
  • AMC_PROP = 0.8                ✅ Standard (inchangé)
  • AMC_TOL_MARQUE = 0.2          ✅ Standard (inchangé)

Justification :
  • Cases VIDES : ~0.7-1% de noirceur
  • Cases CRAYON LÉGER : 8-15% de noirceur
  • Cases STYLO : 15-30% de noirceur

→ Un seuil à 8% donne une marge de sécurité de 7-8% au-dessus des cases
  vides, tout en détectant les cases au crayon léger.
